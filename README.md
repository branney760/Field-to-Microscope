# Three Springs · Field to Microscope — GitHub Pages package

## Publish
1. Extract the ZIP on your computer.
2. Open the GitHub repository for this simulation.
3. Upload the extracted files, keeping index.html, style.css, and app.js together at the publishing root. Upload the files themselves, not the ZIP or its enclosing folder.
4. Configure GitHub Pages to publish the branch and folder containing index.html.
5. Open the published address GitHub provides. Check the microscope image, focus and magnification controls, the three mixed-sample targets, and notebook download before sharing with students.
6. Use the published Pages address as the Canvas activity link.

For an existing Pages site, you can also place the files together in a subfolder and use that subfolder's published address. If you previously published First Look, a separate repository or separate subfolder keeps both activities available. Uploading this index.html over First Look's index.html in the same folder would replace that activity.

## Included
- index.html — page and controls
- style.css — visual theme and responsive layout
- app.js — specimen drawings, evidence, classifications, saved notes, and exports
- .nojekyll — plain static publishing marker
- ABOUT.md — learning flow, scientific scope, and storage details

This is the expanded version: five individual specimens and one mixed preparation, including Painted Run cyanobacteria, diatoms, and budding yeast. Mixed targets have separate records. The header reads CALIFORNIA CONNECTIONS / LEARNING MODULE 3.

No build command, installation, external image files, API key, AI service, or ChatGPT login is required by this code. Your hosting access settings determine who can open the published page. All specimen imagery is drawn by the code and labeled as instructional illustration.

## Student notes
Notes are saved only in the current browser on the current site address. Existing notes from the ChatGPT-hosted site do not transfer automatically to GitHub. Download an existing notebook before moving. Students must download their notebook and submit it through the assigned Canvas activity; the simulation does not submit automatically. Browser storage can be cleared, blocked, or full. Download work before leaving or changing devices.

## Local check
Keep the three application files together and open index.html in a browser. Use the hosted GitHub Pages version for the student workflow and check downloads there. No changes to the deployed ChatGPT-hosted simulation are made by this package.
