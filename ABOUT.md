# Three Springs: Field to Microscope

A buildless, browser-local introductory biology investigation. Serve `dist/` through any static host (including a GitHub Pages repository configured for these three files at its publishing root). There are no external scripts, assets, or runtime dependencies.

## Learning flow

1. Choose among five individual specimens and one mixed preparation, and record fictional environmental conditions. Painted Run includes a cyanobacterium, a diatom, and a budding yeast.
2. Observe simulated microscope fields with calibrated illustration scale bars, focus, and slide movement.
3. Save observations before opening a fictional research identification card and a separate structural model.
4. For the algal and yeast specimens, examine a separate, nucleus-targeted fluorescence illustration.
5. In the mixed sample, select each of three numbered targets (buttons or field click), with separate notes, evidence gates, snapshots, and classifications. Eight specimen records are available in total.
6. Classify cellular organization and specific group; explain evidence and structure–function relationships.
7. Classify plant, fungal, and animal examples; explain a connection across the park.
8. Download an HTML notebook with embedded images, or print the notebook to PDF.

## Scientific scope

All imagery is generated by Canvas code, not microscopy photographs. The fictional samples are generic instructional representatives. Field conditions are not actual park measurements. Genetic identifications are supplied information, not inferred from visible shape. The scale bars apply only to microscope illustrations; structural models and gallery views are not to scale. Nuclear-marker imagery is a distinct prepared view and does not show all DNA. The app does not simulate ecological abundance or survival limits.

## Accessibility and storage

Keyboard arrows pan a focused microscope field. All controls are native buttons, ranges, selects, and text inputs. Equivalent text descriptions accompany each specimen. Color is supplemented by labels, shape, and identification evidence. The clear-view button bypasses manual focusing. Notes and up to three captured views per specimen are stored locally if browser storage is available; nothing is submitted to Canvas or stored on a server. Download the notebook for transfer or submission.

## Validation

JavaScript syntax and a DOM/canvas-mocked interaction workflow were checked, including evidence gating, sample isolation, all classifications, gallery feedback, snapshots, notebook completeness, and self-contained HTML export. A browser rendering pass was unavailable in the build environment.

The expansion preserves existing v1 browser notebooks. Additional checks cover mixed-target isolation, per-target evidence gating, classification of diatoms and yeast, correct model structures, field clicking, high-magnification centering, notebook export, and legacy-note migration.
